# DropoutPredictML

A Machine Learning project focused on predicting student academic outcomes using data preprocessing, exploratory data analysis (EDA), and classification algorithms.

The project aims to classify students into three academic outcome categories: **Dropout, Enrolled, and Graduate**, based on available student-related data.

## Dataset

This project uses the [Predict Students' Dropout and Academic Success](https://doi.org/10.24432/C5MC89) dataset from the UCI Machine Learning Repository.

- **Source:** UCI Machine Learning Repository
- **Dataset ID:** 697
- **Authors:** Realinho et al. (2021)
- **License:** CC BY 4.0
- **DOI:** [10.24432/C5MC89](https://doi.org/10.24432/C5MC89)

The dataset is used for educational and research purposes to develop machine learning models for predicting student academic outcomes.

The dataset is retrieved using the `ucimlrepo` Python package.
